How to Update

Option 1 — Inside the app

Open Assignment Tracker and select Check for Updates. If a compatible OTA update is available, you can choose to install it.

Option 2 — Download the APK

When a new APK is published, download it from this website and install it on your Android device. Back up your assignments before reinstalling. To preserve existing data, update the app without uninstalling the previous version.
